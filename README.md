## 🚀 About the Project

**AI PDF Q&A** allows you to upload a PDF and interact with it like a chatbot.  
Instead of reading long documents manually, simply *ask*:

> 🧠 *"Summarize page 4"*  
> 🔍 *"What are the key points?"*  
> 📑 *"Who is the author?"*

This project extracts the text, processes it with AI, and answers questions based only on your PDF.

---

## ✨ Features

- 📄 Upload any PDF
- 🤖 AI-powered Q&A based on PDF contents
- ⚡ Fast text extraction
- 🧠 Understands context instead of keyword search
- 🎨 Clean minimal interface
